## Repository role

Repository overviews document canonical public identity, purpose, machine-readability expectations and governance boundaries. They are not substitutes for the canonical public pages.

Where a glossary has machine-readable artefacts, those artefacts should preserve stable identifiers, provenance, versioning, explicit relationships and any relevant decision boundaries.
