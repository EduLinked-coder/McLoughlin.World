# Licensing boundary

McLoughlin.World is an open-source public knowledge infrastructure project, but not every repository artefact currently has the same verified licence status.

## Knowledge content

The live McLoughlin.world publication identifies the Strategic Self-Advocacy Ontology and associated knowledge content as licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

Verified licence URL:

https://creativecommons.org/licenses/by/4.0/

The v0.1.0 release records this knowledge-content licence at:

`releases/ssa-ontology/v0.1.0/LICENSE.txt`

## Source code and tooling

GitHub currently detects no repository-level licence for `EduLinked-coder/McLoughlin.World`.

The repository contains source code and operational artefacts including Jekyll templates, Python validation scripts and GitHub Actions workflows. Those artefacts must not be assumed to inherit CC BY 4.0 merely because the published knowledge content uses that licence.

Issue #4 tracks the canonical decision about the repository/software licence:

https://github.com/EduLinked-coder/McLoughlin.World/issues/4

Until that decision is made, automation must not invent or infer MIT, Apache-2.0, GPL, or another software licence.

## Third-party material

Third-party sources, quotations, referenced datasets, embedded assets and other externally sourced materials retain their applicable rights and licence conditions. Publication in this repository does not override those conditions.

## Machine rule

Consumers should interpret licence metadata at the narrowest applicable resource level:

1. use explicit licence metadata attached to the specific release, dataset or resource;
2. do not propagate the knowledge-content licence automatically to source code or tooling;
3. do not infer a licence from repository visibility alone;
4. where no explicit licence exists, treat reuse permissions as unresolved until a canonical licence decision is published.
