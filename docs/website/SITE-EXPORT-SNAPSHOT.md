## Reconciliation rule

This export is a high-value development snapshot, but it is not treated as an immutable substitute for the live public website. Repository reconciliation follows these rules:

1. Preserve canonical public URLs from the exported records.
2. Preserve the website's explicit versioning, status, provenance and licence information.
3. Use the live website to verify claims that are time-sensitive or may have changed since export.
4. Do not infer that an exported route is publicly navigable merely because it exists in the export.
5. Keep release datasets and source snapshots separate from canonical public identifiers.
6. Prefer generated registries and indexes over manually retyping concept metadata.
