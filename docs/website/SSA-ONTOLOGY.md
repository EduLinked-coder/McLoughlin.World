# Strategic Self-Advocacy Ontology

**Canonical public URL:** https://www.mcloughlin.world/glossaries/ssa-lexicon/

**Current release:** `0.1.0`

**Released:** 2026-07-29

The Strategic Self-Advocacy Ontology is survivor-authored public semantic infrastructure for naming patterns that distort, extract, silence, exclude or appropriate lived experience.

The v0.1.0 release publishes:

- 93 canonical concept pages;
- 17 concept schemes;
- Schema.org-compatible `DefinedTerm` and `DefinedTermSet` JSON-LD;
- browse, documentation, downloads, governance and about surfaces;
- stable canonical web identifiers and visible provenance.

## Download formats

The public v0.1.0 package exposes JSON-LD, Turtle, RDF/XML, JSON and CSV together with a complete release ZIP, release manifest, changelog, licence and README.

All RDF formats are intended to serialise the same canonical graph.

## Governance principles

Published concept URIs should not be reassigned to different meanings. Definition, scope, relationship and status changes should be included in release notes. Broader, narrower, causal and equivalence relationships should be asserted only when sufficiently evidenced and governable.

Reuse is encouraged under CC BY 4.0 with clear attribution to the ontology and creator.

## Status model

- `Draft` — proposed and under review.
- `Published` — included in a numbered release.
- `Deprecated` — retained for compatibility but no longer preferred.
- `Superseded` — replaced by a specifically identified concept.
