# Publications Layer

**Canonical public URL:** https://www.mcloughlin.world/publications/

The Publications layer contains the canonical published works of the McLoughlin.World semantic infrastructure.

Each publication is intended to have a permanent identifier and participate in an interconnected knowledge graph. Publications are versioned, citable, machine-readable and linked to the concepts, glossaries, datasets and specifications on which they depend.

## Current public entry points

- Releases — https://www.mcloughlin.world/releases/
- Editions — https://www.mcloughlin.world/editions/
- Blog — https://www.mcloughlin.world/news/
- Brethna — https://www.mcloughlin.world/brethna/
- Frameworks — https://www.mcloughlin.world/frameworks/

## Repository expectation

Repository documentation should distinguish publication identity from working notes. Stable public references should preserve canonical URL, title, version or edition information, provenance and machine-readable companions where applicable.
