# McLoughlin.world — Glossaries Layer

**Public index:** https://www.mcloughlin.world/glossaries/

The Glossaries layer provides controlled vocabularies used throughout McLoughlin.world's public knowledge infrastructure.

Each glossary is intended to define a coherent semantic domain using stable identifiers, explicit relationships, provenance and open semantic standards so publications, datasets, software and AI systems can interpret the same concepts consistently.

## Semantic publication expectations

Where a glossary has machine-readable outputs, the preferred publication family includes:

- canonical HTML page;
- JSON;
- JSON-LD;
- CSV;
- Turtle;
- RDF/XML;
- validation schema where relevant;
- examples;
- provenance/source registry;
- release and integrity metadata.

Not every historical glossary currently has every representation. Repository work should close those gaps without changing canonical public identifiers.
