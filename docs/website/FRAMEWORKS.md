## Publication boundary

Framework pages are public knowledge resources distinct from SSA Ontology concepts and glossary concept schemes. Repository mirrors should therefore retain the distinction between:

- framework/publication prose;
- controlled vocabulary definitions;
- ontology concepts and relationships;
- downloadable datasets and releases.

The live page remains canonical unless a repository artefact explicitly declares itself as a versioned source representation.
