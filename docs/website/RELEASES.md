# Releases

McLoughlin.world exposes both a general releases surface and a dedicated SSA Ontology releases surface.

## Canonical routes

- General releases: https://www.mcloughlin.world/releases/
- SSA Ontology releases: https://www.mcloughlin.world/glossaries/ssa-lexicon/releases/

## SSA Ontology v0.1.0

The site export identifies the first public SSA Ontology release as **v0.1.0**, released **29 July 2026**, containing:

- 93 canonical concept pages;
- 17 concept schemes;
- permanent human-readable concept URLs;
- machine-readable downloadable representations;
- explicit status, provenance and governance metadata.

## Release discipline

Repository releases should preserve:

- immutable version identifiers;
- release date;
- canonical concept and scheme counts;
- changelog or release notes;
- downloadable format inventory;
- integrity/checksum information where available;
- provenance and licensing metadata;
- explicit distinction between current public state and historical releases.

Definitions and identifiers should not be silently overwritten when a versioned release is intended to remain citable.
