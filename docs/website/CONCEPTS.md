# Concepts Layer

**Canonical public URL:** https://www.mcloughlin.world/concepts/

The Concepts layer provides the canonical semantic objects used throughout McLoughlin.world.

Each concept is published as an independently addressable resource with a permanent identifier, formal definition, semantic relationships and a machine-readable representation. Concepts form the stable semantic foundation used by publications, glossaries, datasets and software.

## Current public entry points

- Ontology — https://www.mcloughlin.world/ontology/
- SSA Ontology / Lexicon — https://www.mcloughlin.world/glossaries/ssa-lexicon/
- Taxonomy for Recognising Extraction — https://www.mcloughlin.world/glossaries/taxonomy-for-recognising-extraction/
- Brethna — https://www.mcloughlin.world/brethna/

## SSA concept publication

SSA Ontology v0.1.0 publishes **93 canonical concept pages**. Each concept has a stable web identifier and should be treated as a reusable semantic object rather than text embedded only inside a glossary.

Concept identifiers should remain stable across releases. Definition, scope, relationship and status changes should be visible in release history rather than silently overwritten.

## Machine-readable expectation

The live SSA concept pages embed Schema.org-compatible `DefinedTerm` JSON-LD. Repository representations should preserve canonical URI, preferred label, definition, concept scheme, provenance and publication status where available.
