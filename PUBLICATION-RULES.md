# SSA Lexicon publication rules

1. One canonical URI for each ontology object.
2. Human-readable and machine-readable representations come from the same canonical record.
3. Every page is a typed ontology or publication object.
4. Use open standards before inventing vocabulary.
5. Reuse shared components and canonical templates.
6. Accessibility is structural and present on every SSA page.
7. Machine-readable language is embedded on canonical pages.
8. Relationships are declared rather than inferred.
9. Published releases are immutable.
10. Provenance, authorship, licence, status and version are explicit.
11. Stable URLs are preserved.
12. Identity is independent of Oncord presentation.
13. The site forms a traversable Linked Data graph.
14. Every release is self-describing and checksummed.
15. Original meaning is preserved; translations and summaries are mappings, not identities.
16. Transformations preserve information and prior versions.
